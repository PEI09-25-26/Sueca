# Suecada Website

Static landing page for the Suecada app.

## Edit these files

- `index.html` controls the page sections and text.
- `styles.css` controls the visual design.
- `script.js` controls the download button behavior.
- `assets/suecada-logo.png` is the hero logo.

## Open it

If the gateway server is running, open:

```text
http://127.0.0.1:8080/site/
```

You can also open `index.html` directly in a browser.
